# Miner Source Code

The CPU miner source code is available in the
[GitHub Releases](https://github.com/RCPUcoin/RCPU/releases) or
as a separate package.

> **Note:** The full cpuminer source tarball is not stored in this
> repository to keep the repo size small. Download it from Releases.

## Building from source

See the build instructions in the release notes or miner documentation.

The pool also includes reference implementations:
- `cpu-miner.c` - Basic CPU miner reference
- `randomx-miner.c` - RandomX miner reference
